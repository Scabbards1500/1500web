# 样式

| 格式   | 写法                         | 效果                        |
| ---- | -------------------------- | ------------------------- |
| 一级标题 | `# 标题`                     | 最大标题                      |
| 二级标题 | `## 标题`                    | 小一级标题                     |
| 三级标题 | `### 标题`                   | 再小一级                      |
| 加粗   | `**重点**`                   | **重点**                    |
| 斜体   | `*文字*`                     | _文字_                      |
| 删除线  | `~~删除~~`                   | ~~删除~~                    |
| 行内代码 | `` `print()` ``            | `print()`                 |
| 链接   | `[UCSD](https://ucsd.edu)` | [UCSD](https://ucsd.edu/) |

注意：**标题的 `#` 后面要有空格。**


**颜色**
Markdown 本身**没有统一的文字颜色语法**，通常用 HTML：

```
<span style="color: red;">这是红色文字</span>

<span style="color: #2563eb;">这是蓝色文字</span>
```

背景高亮可以这样写：

```
<span style="background-color: yellow;">黄色背景高亮</span>
```


# 插入

**列表：**

```
- 第一项
- 第二项
  - 第二项的子项

1. 第一步
2. 第二步
```

**引用：**

```
> 这是引用的内容。
```

效果：

> 这是引用的内容。

**图片：**

```
![图片说明](图片地址或路径)
```

**表格：**

```
| 名称 | 分数 |
| --- | --- |
| Alice | 90 |
| Bob | 85 |
```

**待办清单：**

```
- [ ] 没完成
- [x] 已完成
```



**代码块：**用三根反引号包住代码，后面可以标语言。

````
```python
print("Hello!")
```
````
