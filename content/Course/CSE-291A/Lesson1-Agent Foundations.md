# Agent、LLM 和 Workflow 的区别
    
    - LLM 负责生成内容；Agent 能感知环境、做决策并执行行动。
    - Workflow 的执行路径由开发者预先规定；Agent 根据当前结果动态选择下一步。
- **Agent 的运行循环**
    
    - 基本过程：**观察状态 → 选择行动 → 执行工具 → 接收结果 → 继续决策**。
    - 模型生成工具名称和参数，运行时负责检查权限、执行调用，再把结果交回模型。
- **规划与推理方法**
    
    - **CoT**：逐步推理，把复杂问题拆成小步骤。
    - **ToT**：生成多个候选推理分支，通过评估和搜索选择路径。
    - **ReAct**：交替进行推理、行动和观察，根据工具反馈调整后续步骤。
- **Agent 的记忆**
    
    - **短期记忆**：当前上下文中的任务信息和交互历史，受上下文窗口限制。
    - **长期记忆**：存储在外部数据库或向量库中，通过检索取回。
    - 还介绍了语义记忆（知识）、情景记忆（经历）和程序性记忆（技能）。

# Harness 与 Agent 基础设施
    - **Harness** 是运行 Agent 的软件，管理上下文、模型与工具循环、执行和权限。
    - 持久工作区保存文件及执行状态；沙箱负责隔离。
    - 系统研究关注推理效率、资源管理、状态保存、故障恢复与安全。
